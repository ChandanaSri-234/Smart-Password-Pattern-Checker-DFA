
# Smart Password Pattern Checker Using DFA

## Project Description
A Python-based password validation system using
Deterministic Finite Automata (DFA).

## Objectives
- Validate password length.
- Detect uppercase and lowercase characters.
- Identify digits and special characters.
- Detect prohibited password patterns.
- Display DFA state transitions.
- Classify passwords as valid or invalid.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SVG

## Security Rules
1. Minimum 8 characters.
2. At least one uppercase character.
3. At least one lowercase character.
4. At least one digit.
5. At least one special character.
6. No prohibited patterns.

## How to Run

Install dependencies:

pip install -r requirements.txt

Run application:

python main.py

Open browser:

http://127.0.0.1:5000

## Expected Output
The application displays:
- Password validation result.
- Security requirement checklist.
- Violated rules.
- DFA state transition diagram.
